# Neural Networks Practice Repository

This repository contains a series of neural network practical assignments and exercises developed as part of a learning project.

## Contents

- `TP1_Redes_Neuronales_Funcionando.ipynb` — First neural network exercise and working implementation.
- `TP2_Redes_Neuronales.ipynb` — Second assignment focused on neural network concepts and experimentation.
- `TP3_Redes_Neuronales.ipynb` — Third assignment with additional neural network practice.

## Purpose

The goal of this repository is to document and store the work completed while learning about:

- artificial neural networks
- training and optimization
- activation functions
- backpropagation
- model experimentation and evaluation

## Requirements

To run the notebooks, you will typically need:

- Python 3
- Jupyter Notebook or JupyterLab
- common scientific libraries such as NumPy, Matplotlib, and scikit-learn, depending on the assignment

## How to use

1. Open the notebooks in Jupyter.
2. Run the cells in order.
3. Review the results and adapt the experiments as needed.
